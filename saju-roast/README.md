# 🔥 초정밀 사주 분석 — HARD ROAST MODE

`https://jhfafa2010.github.io/my-to-do-app/saju-roast/`

출생 정보를 넣으면 만세력을 실제로 계산하고, 8개 섹션의 근거 기반 분석(ROAST)을 보여 주는 정적 웹 앱입니다. 빌드 없이 동작하며, 모든 계산은 브라우저 안에서 끝납니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `styles.css` | 다크·크림슨 테마, 모바일 우선 반응형 |
| `engine.js` | 만세력 계산 엔진 (사주 4주, 십성, 12운성, 오행, 격국, 용신, 합충형파해, 신살, 대운, 세운) |
| `analysis.js` | 8개 섹션 분석 텍스트 생성 (근거 → 예상 행동 → ROAST) |
| `prompt.js` | AI 정밀 프롬프트 생성 (계산된 만세력을 채워 클립보드 복사) |
| `app.js` | 폼·렌더링·localStorage 저장 |
| `lunar.js` | lunar-javascript (寿星天文历 기반, MIT) 로컬 번들 |

## 계산 방식

1. 입력 시각에서 **서머타임**(1948~1951, 1955~1960, 1987~1988)을 제거합니다.
2. **한국 표준시 이력**(1908~1911·1954~1961 UTC+8:30, 그 외 UTC+9)을 반영합니다.
3. **진태양시 보정**(경도차, 선택 시 균시차)을 적용해 시주·일주를 냅니다.
4. 년주·월주는 **절입(節入) 절대시각** 기준으로 계산합니다(입춘·망종 등 12절).
5. 자시 일주는 **조자시(00:00)** / **야자시(23:00)** 중 선택합니다.
6. 출생시간 미상이면 시주 없이 6글자로 계산하고, 그 사실과 한계를 화면에 표시합니다.

## 참고

- 음력 변환은 lunar-javascript를 사용하며, 한국천문연구원 기반 라이브러리(`korean-lunar-calendar`)로 표본 날짜를 교차 확인했습니다(음력 날짜·일주 일치).
- 월주는 음력 월이 아니라 **24절기**로 나눕니다(자평명리 기준). 음력 월 기준으로 계산하는 간이 만세력과 결과가 다를 수 있습니다.
- 이 분석은 전통 명리학 체계 내부의 해석이며, 과학적으로 검증된 예측이 아닙니다.
